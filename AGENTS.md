# HACKEAT — web informativa pública

Este repositorio sólo contiene material autorizado para publicación.
No copiar código, documentación interna, datos de cuentas o configuración de la plataforma.
No añadir formularios, login, OAuth, pedidos, pagos, analítica o llamadas al servidor aquí.
GitHub Pages es alojamiento estático informativo; respetar sus límites de uso.

Antes de editar leer el issue y PLAN.md. Usar rama → validación → PR → CI → merge.
No push directo a main. Ejecutar python scripts/validate_site.py y revisar móvil/escritorio.
Usar identidad HACKEAT propia y recursos locales. No instalar dependencias sin necesidad.
Los runners de este repo público son hospedados GitHub, nunca los privados de desarrollo.
